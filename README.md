# جستجوی زنده (Live Search)

یه پروژه‌ی تمرینی برای یادگیری جستجوی لحظه‌ای سمت کلاینت با تکنیک Debounce، در جاوااسکریپت خالص — بدون هیچ کتابخونه یا فریم‌ورکی.

## دمو (لینک آنلاین)

[https://ghazal-hassanabadi.github.io/live-search-js/]

## این پروژه شامل چیه؟

یه فروشگاه ساده با یه باکس جستجو که همزمان با تایپ کاربر، محصولات مرتبط رو فیلتر و نمایش می‌ده:

- **Live Search** — فیلتر کردن لیست محصولات بر اساس متن ورودی، بدون رفرش صفحه
- **Debounce** — تاخیر در اجرای جستجو تا زمانی که کاربر تایپ‌کردن رو متوقف کنه، برای جلوگیری از اجرای غیرضروری تابع در هر کاراکتر
- نمایش نتایج به‌صورت گرید ریسپانسیو (۲ ستون در موبایل، ۴ ستون در دسکتاپ)
- پیام «محصول مورد نظر یافت نشد» برای حالت بدون نتیجه

## مفاهیمی که تمرین شده

- رویداد `input` و پیاده‌سازی تابع `debounce` با `setTimeout`
- متد `Array.prototype.filter()` برای فیلتر کردن آرایه‌ی داده‌ها
- ساخت داینامیک عناصر DOM با `createElement` و `innerHTML`
- `position: absolute` و مفهوم Containing Block در CSS
- `display: grid` و `grid-template-columns` برای چیدمان ریسپانسیو
- استفاده از بعضی از قسمت های تمرین قبلی فیلتر محصولات 
- طراحی ریسپانسیو با media query

## تکنولوژی‌های استفاده‌شده

- HTML5
- CSS3
- JS

## استفاده از هوش مصنوعی

در این پروژه، از هوش مصنوعی (AI) به عنوان یک ابزار کمکی برای یادگیری و رفع اشکال استفاده شده است. از AI برای دیباگ کردن مشکلات CSS (مثل جایگذاری نادرست عنصر جستجو و رفتار گرید)، توضیح مفاهیم مربوط به Positioning و Grid، و بازخورد درباره ساختار کد استفاده کردم. نوشتن کد اصلی جاوااسکریپت و CSS توسط خودم انجام شده است.
